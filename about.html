I'm a Full-Stack MERN Developer and Cybersecurity student at Miva Open University, building web applications that are secure by design, not by accident.

What I've Built

I designed and built MoonStore, a multi-tenant marketplace SaaS for African fashion vendors to create their own online store, completely solo, from architecture through deployment. It handles secure data isolation between hundreds of sellers, automated split payments via Paystack subaccounts, and real-time buyer-seller chat.

I also built MoonBlog, a full-stack personal blog platform built with the MERN stack (MongoDB, Express, React, Node.js). Admins can create, edit, delete, and publish posts, while users browse and read published posts by category.

How I Work

Security isn't a feature I add at the end, it's part of how I architect from day one: request validation, JWT authentication, rate-limiting, and strict data isolation are built in from the start, not patched in after something breaks. My cybersecurity background means I think about how a system could be attacked while I'm still building it, not after.
